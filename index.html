Data Notes

  • Stock vs Flow: Stock = a point-in-time total (e.g., total Indians resident as of year-end). Flow = new arrivals/entries during that calendar year. Different units — never combined on the same chart axis.
  • Indian share of a country's foreign population/workforce = Indian ÷ that same country's own Total Foreigners figure, for the same year. It is never pooled or averaged using other countries' totals in the denominator.
  • "Avg. Indian share" KPIs are a simple, unweighted average of each individual country's own share — not a single global percentage weighted by population size.
  • Each table has its own country list, which differs because the underlying data coverage varies by country and year. Every chart lists exactly which countries are reflected based on the active filters and available data.
